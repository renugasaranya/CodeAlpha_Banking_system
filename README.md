Banking System
A simple C++ console-based Banking System developed as part of the CodeAlpha C++ Internship.
Project Description:

This program simulates basic banking operations using C++ classes and objects. It allows users to create customer accounts and perform different banking transactions.

Features:

- Create customer and account
- Deposit money
- Withdraw money
- Transfer funds between accounts
- Display account information
- View transaction history
- Check insufficient balance
- Store multiple customer accounts

Technologies Used:

- Language: C++
- Concepts Used:
  - Classes and Objects
  - Arrays
  - Functions
  - Loops
  - Conditional Statements
  - Encapsulation

How to Run:

1. Download or clone this repository.
2. Open "Bank.cpp" in a C++ compiler.
3. Compile the program.
4. Run the program.
5. Select an option from the Banking System menu.
6. Enter the required details.

Banking Operations:

The system provides the following menu options:

1. Create Customer and Account
2. Deposit
3. Withdraw
4. Transfer Funds
5. Display Account Information
6. View Transactions
7. Exit
